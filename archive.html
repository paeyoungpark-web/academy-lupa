지금은 샘플 데이터가 표시되고 있습니다. 내 과목·학사 데이터를 JSON으로 가져오면 모든 숫자가 자동으로 바뀝니다.

AI 석사와 박사과정 수업을
검색 가능한 지식으로

AI 석사와 박사과정에서 들은 수업의 강의안·수업영상·과제·공지가 Google Classroom, Drive, 학사시스템 세 곳에 흩어져 있었습니다. 무엇을 어디서 배웠는지 확인하려면 매번 로그인해서 찾아 들어가야 했습니다. 그래서 파일 하나로 열리는 개인 학습 아카이브를 만들었습니다. 서버도 계정도 필요 없습니다.

01 · 수집원본을 복제하지 않는 색인

Classroom 44개 수업의 제목·분류·링크만 수집합니다. 강의 영상과 교재 원본은 그대로 학교에 둡니다.

02 · 정규화제목에서 사실을 분리

“[aSSIST Ph.D.] 과목명(25.09 클래스) 교수명” 한 줄에서 과정·과목·기수·교수를 갈라냅니다.

03 · 교차검증학사 성적표와 대조

Classroom의 기수 표기는 실제 학기와 달랐습니다. 성적표의 과목명과 매칭해 9개 과목의 학기를 바로잡았습니다.

04 · 계산숫자를 손으로 적지 않기

통계·학기 목록·영상 개수·평점평균·졸업요건을 모두 데이터에서 계산합니다. 평점 3.99는 학사시스템 값과 일치합니다.

05 · 추적지식화 7단계

색인 완료 → 요약 → 전사 → 원자노트 → 업무 활용. 과목마다 지금 어디쯤인지 한 화면에서 봅니다.

06 · 점검졸업요건 자동 점검

37학점·평점 3.5·필수과목·학술지 게재 요건을 체크리스트로 만들어 남은 것을 보여줍니다.

설계 원칙

원본을 복제하지 않습니다. 제목·분류·원본 링크만 저장하는 색인입니다. 수업 영상은 다운로드 금지인 경우가 많아, 내려받거나 외부 AI에 일괄 업로드하지 않는 것을 전제로 설계했습니다.

서버가 없습니다. HTML 파일 하나에 데이터가 들어 있고, 진행상태와 메모는 브라우저 안에만 저장됩니다.

숫자를 손으로 적지 않습니다. 화면의 모든 수치는 데이터에서 계산됩니다. 데이터를 바꾸면 화면이 따라옵니다.

이 공개본에 대하여

실제 운영본에는 제 수업 자료의 원본 링크와 성적이 들어 있습니다. 공개본은 다음을 처리했습니다.

· 교수·조교 이름 40명 마스킹 (김○수 교수)
· Classroom·Drive 원본 링크 전부 제거
· 학번·연락처·소속 제거, 제출 과제 파일명의 본인 이름은 “본인”으로

과목명·학기·자료 제목·개수는 그대로 두어 무엇을 배웠는지는 보이도록 했습니다.

how it was made

만든 방식

단일 HTML + 바닐라 자바스크립트. 빌드 도구도 프레임워크도 쓰지 않았습니다. 데이터 변환은 Node 스크립트 3개(수집본 정규화 · 공개용 마스킹 · 데이터 내장 빌드)로 나눠 두어, 자료가 늘어나면 명령 두 줄로 다시 만듭니다. 설계와 구현은 Claude Code로 진행했고, 정규화 규칙과 졸업요건 해석은 학사시스템·학교 안내 메일 원문과 대조해 확인했습니다.

권장 결론

전 과목 전체 전사보다, 교재·과제 요약 → 영상별 1쪽 요약 → 필요한 영상만 전사가 효율적입니다. 전사는 검색과 정확한 인용이 필요한 영상에만 적용하고, 지식노트에는 개념·근거·적용처를 남깁니다.

01 · 완료원본 색인

과목·자료·영상·과제·CV 원본 링크를 보존했습니다.

02 · 우선교재·과제 요약

강의안과 내가 제출한 과제로 수업의 핵심 구조를 먼저 복원합니다.

03 · 기본영상 1쪽 요약

핵심 개념, 사례, 질문, 적용 아이디어와 원본 링크를 남깁니다.

04 · 선택챕터 전사

검색·인용이 필요한 구간만 타임스탬프와 함께 전사합니다.

05 · 지식화Obsidian 원자노트

한 노트에 한 개념. 논문·실무·강연 활용처를 연결합니다.

06 · 재사용업무 적용

제안서, 강의, 연구설계, 의사결정에 실제 사용한 이력을 남깁니다.

저작권·보안 가드레일: 일부 Classroom은 “수업 영상 다운로드 불가”와 저작권 주의사항을 명시합니다. 원본 영상을 내려받거나 외부 AI에 일괄 업로드하지 않습니다. 내 학교가 제공한 자막·전사본이 있으면 그것을 우선 사용하고, 자동 전사는 개인 학습 허용 범위를 확인한 뒤 진행합니다. NotebookLM에는 우선 본인 과제와 직접 작성한 요약노트만 넣는 것이 안전합니다.

Google 계정 인덱스

여러 Google 계정에 로그인돼 있으면 링크가 권한 오류로 열리지 않습니다. Classroom 주소창의 /u/N/ 숫자를 넣으면 모든 링크에 적용합니다. 비우면 원래 링크를 씁니다.

JSON 직접 편집

구조는 샘플데이터-v2.json과 같습니다. 적용 전에 검증하며, 오류가 있으면 적용하지 않습니다.
